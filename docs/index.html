ResNet-18, re-plumbed for 32×32 images

Three edits to torchvision's ImageNet ResNet-18 keep spatial resolution on tiny inputs and resize the head to 100 classes.

Result: the first residual stage sees 32×32 feature maps instead of 8×8.

Interactive · learning-rate schedule

StepLR only decays after epoch 60

Drag to see the learning rate train.py uses at each epoch. The markers show where each run stopped.

The 10- and 20-epoch runs stop before the first decay, so they train at lr 0.1 the whole time. That explains the noisy validation curve after epoch 7 and much of Exp-01's "undertrained" result. Scale the schedule to the run length, for example with CosineAnnealingLR(T_max=epochs).

Run it yourself

Train, evaluate, and launch the live classifier

The live demo needs a trained checkpoint, which lives on Google Drive. These commands reproduce everything on this page.

Train

python train.py \
  --epochs 200 --lr 0.1 \
  --exp-name CIFAR100_Exp03

Evaluate

python evaluate.py \
  --checkpoint checkpoints/model_best.pth \
  --save-dir eval_results

Live demo (Gradio)

python demo.py \
  --checkpoint checkpoints/model_best.pth \
  --share

--share prints a temporary public URL. For a permanent link, push demo.py and the checkpoint to a Hugging Face Space.
